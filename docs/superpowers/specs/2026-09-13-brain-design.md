## 目的

Obsidian vault に蓄積された脳・意識まわりのノート9本を素材に、脳の仕組みを一本の読み物として再編集し、m-note.uk の新セクションとして公開する。

読後に残ってほしい一つの理解は「自分が見ている世界は、自分の脳が作っている」。

## 立ち位置

解説を主軸に置き、各章末に「残る問い」を添える。専門家ではない個人のまとめであり、断定しすぎない。第1章の脳の構造・機能は一般的な脳科学の知識で記述する（vault に素材がないため）。それ以外の章は vault のノートを土台にする。

## 素材（Obsidian vault のノート）

土台になるノート:

- 【脳科学】脳は世界を予測し、誤差だけを処理している
- 【脳科学】何もしない時間こそが、脳を整理している
- 【生物】新皮質は、理性の脳ではなかった
- 【知的生産】自己と意識は、同じではなかった
- 【知的生産】脳が選択して構成した世界
- 【知的生産】思い出せないのに、嗅ぐと蘇る
- 【知的生産】世界を遮って、内側を立ち上げる
- 【知的生産】頭の中が一瞬、真っ白になる

背景として参照する対話ログ:

- 脳・意識・「私」とは何か — 千の脳理論から自己へ
- 脳の進化と「私がここにいる」という意識
- 意識とは何か ― 麻酔・微小管・物理現象・自由意志をつなぐ

vault の内容はそのまま転載しない。公開用の文章として書き直す。

### 各章の型

1. 小見出しラベル（`予測` `選択` `再構成` のような一語）
2. 本文 2〜4段落
3. 図解 1〜3点（インラインSVG）
4. 章末に「残る問い」ブロック（罫線で囲った小さなブロック）

「残る問い」は vault の「まだ言葉になっていないこと」を土台に、公開用に整えて書く。解説の断定に対して余白を残す役割。

### 第1章の内訳

4つのスケールで降りていく。

1. 細胞 — ニューロン、シナプス、電気信号と神経伝達物質（ドーパミン・セロトニン・GABA・アセチルコリン）。約1000億個のニューロンと、その数百倍のシナプス結合。
2. 部位 — 脳幹（呼吸・覚醒）／小脳（運動の調整・手続き記憶）／視床（感覚の中継）／扁桃体（情動の警報）／海馬（記憶の索引）／大脳新皮質の4葉（前頭＝計画と抑制、頭頂＝空間と身体、側頭＝聴覚・言語・記憶、後頭＝視覚）。部位と役割の一覧表を置く。
3. ネットワーク — 部位の寄せ集めではなく、領域間の結合が機能を生む。CEN（実行系）／DMN（デフォルト）／サリエンス・ネットワーク（切り替え役）の三つ組。第7章の伏線。
4. 代謝と可塑性 — 体重の約2%で全エネルギーの約20%。使われる結合は強まり、使われない結合は刈り込まれる。

章末の渡し文: 「部位と役割を並べると、脳は分業する機械のように見える。しかし実際に起きていることは、もっと奇妙だった。」

## ビジュアル方針

- 基調色: 藍。ライト `#2f4a7c` 系／ダーク `#8fb0e0` 系
- 差し色: 朱。ライト `#b4553f` 系。「誤差」「ズレ」を表す箇所にだけ使う。本文中の語も図の破線も同じ朱にして視覚的に結ぶ
- 背景: ライト `#f2f2f0` ／ダーク `#14161a`
- フォント: Noto Sans JP（本文）／ Noto Serif JP（見出し・引用）
- 最大幅720px、左右パディング24px
- トーン: 静かで余白のある日本語サイト。ハブの文体から浮きすぎない

## 技術仕様

- 自己完結の静的HTML。CSS・SVG すべてインライン。外部依存は Google Fonts のみ
- `<html lang="ja">`、meta description あり
- favicon: 絵文字 🧠 の data URI（既存セクションと同じ手法）
- CSS変数 ＋ `prefers-color-scheme` でライト／ダーク両対応
- JSは使わない。目次は素のアンカーリンク ＋ `scroll-behavior: smooth`
- 見出し階層: `h1`（ページタイトル）→ `h2`（章）→ `h3`（章内の節）
- モバイルで横スクロールが発生しないこと
