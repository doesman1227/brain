# 脳の仕組み 複数ページ化 設計仕様

作成日: 2026-09-15
公開先: https://m-note.uk/brain/
ローカル: `~/Claude/brain/`
前提: 2026-09-13 の単一ページ設計（`2026-09-13-brain-design.md`）を置き換える

## 目的

1ページ完結の読み物だった `brain` セクションを、脳についての解説サイトに組み替える。

本編は「脳は何でできているか → どういう仕組みで動いているか → それが日々の活動にどうつながるか」
を順に辿る。理論はコラムとして本編の外に置き、読み飛ばせるようにする。

## 方針の転換

現行ページは「予測符号化 → 千の脳 → 自己モデル」という理論主導の構成になっている。
新しい構成では重心を逆にする。

- 本編 = 具体の解説（細胞・部位・電気信号・伝達物質・知覚・記憶・注意・意思決定）
- コラム = 理論（予測符号化・自由エネルギー原理・千の脳・DMN・自己モデル・意識・無我・AI）

現行の本文18,000字と図14点は捨てずに、基礎解説側とコラム側に振り分ける。

## サイト構造

全HTMLをルート直下にフラットに配置する。階層を作らないので、どのページからも
`css/style.css` が同じパスで参照でき、相互リンクも壊れにくい。

```
brain/
├ index.html            入口・全体マップ
├ css/style.css         共通スタイル

├ anatomy.html          02 脳の地図
├ networks.html         03 つながりが機能をつくる
├ signal.html           04 電気で走る
├ synapse.html          05 すきまを渡る
├ chemicals.html        06 神経伝達物質
├ perceive.html         07 感じる
├ remember.html         08 覚える・思い出す
├ attention.html        09 注意と情動
├ decide.html           10 決める・動く
│
├ columns.html          コラム一覧
├ prediction.html       予測符号化
├ free-energy.html      自由エネルギー原理
├ thousand-brains.html  千の脳理論と座標系
├ dmn.html              デフォルト・モード・ネットワーク
```

ファイル名は番号ではなく内容で付ける。あとから章を挟んでもURLがずれないため。

現行URL `m-note.uk/brain/` は入口として維持する（外部リンクが切れない）。中身は入れ替える。

## 各ページの共通構造

```
ヘッダー      BRAIN ｜ 脳の仕組み          ← m-note トップ
パンくず      脳の仕組み › 第2部 仕組み › すきまを渡る
リード文      このページで分かることを2〜3行
本文          見出し・段落・図・表
コラム誘導    → コラム：予測符号化（本文中の該当箇所にカードで）
前へ / 次へ   ← 04 電気で走る    06 神経伝達物質 →
サイトマップ  全20ページへのコンパクトな一覧
フッター      免責 ＋ ← m-note トップ
```

JavaScriptは使わない。回遊は「前へ／次へ」と各ページ末尾の全体マップで担保する。

## ビジュアル方針

暖色系・丸みのあるデザイン。旧設計の藍を温かい茶褐色に置き換え、朱は残す。
「予測＝褐色の実線／誤差＝朱の破線」という図の語彙は維持する。

| 役割 | 変数 | ライト | ダーク |
|---|---|---|---|
| 地 | `--ground` | `#f7f1e7` | `#191410` |
| 紙（カード） | `--paper` | `#fffcf7` | `#241d16` |
| 本文 | `--ink` | `#33261c` | `#f0e5d7` |
| 本文（弱） | `--ink-soft` | `#6b5748` | `#bca893` |
| 本文（最弱） | `--ink-faint` | `#9e8a78` | `#8a7462` |
| 主色（構造・予測） | `--primary` | `#8a5a2b` | `#dca76a` |
| 主色（淡） | `--primary-soft` | `#c9a97e` | `#6b5033` |
| 差し色（誤差・信号） | `--accent` | `#cc4b33` | `#e9765c` |
| 罫線 | `--line` | `#e3d7c6` | `#382c22` |
| 部位トーン | `--l0`〜`--l4` | `#fbf4e7` → `#c9a46a` | `#221b14` → `#4e3c2d` |

- 書体: 見出し・ラベル・図の文字は **Zen Maru Gothic**（丸ゴシック、500/700）。
  本文は長文のため **Noto Sans JP**（400/500/700）を維持する。明朝は使わない。
- 丸み: カードと図の角 16px、チップとラベルはピル形（999px）、前へ/次へのボタンも丸く。
  影は柔らかく拡散させる。
- 最大幅 720px、左右パディング 24px。`prefers-color-scheme` でライト／ダーク両対応。

## 本編とコラムの描き分け

同じデザイン言語のまま、コラムだけ3点を変える。

- ページ上部のラベルを `COLUMN` とし、差し色（朱）で表示。本編は `PART 2 — 仕組み` のように主色
- 本文の地をわずかに `--paper` 側へ寄せ、手触りを変える
- 本編からコラムへのリンクはインラインではなく小さなカードにする。
  「理論の話に入るので読み飛ばしても本編は続く」ことが見た目で分かるようにする

## CSS構成

現行の `<style>` ブロックを `css/style.css` に切り出し、以下を足す。

- ページ間ナビ（パンくず・前後リンク・サイトマップ・コラム誘導カード）
- 丸みと暖色のトークン
- 図のクラス（`.fig` `.s-i` `.s-e` `.box` `.gyri` `.chip` ほか）

SVGの `<marker>` 定義は同一ドキュメント内でしか参照できないため、共通CSSには出せない。
各ページ冒頭に同じ `<svg>` defs ブロックを複製する。

## 段階リリース

この規模は一度に作りきれない。部ごとに公開し、途中で止まっても読める状態を保つ。

1. 共通CSS + index + 第1部（cells / anatomy / networks）
2. 第2部（signal / synapse / chemicals）
3. 第3部（perceive / remember / attention / decide）
4. コラム（columns + 9本）

各段階でコミットし、ビルド完了と表示を確認してから次へ進む。
未完成のページへのリンクは、その段階では出さない。

## 検証

- 各ページでライト／ダーク両モードの表示を確認
- 375px幅で横スクロールが出ないこと
- パンくず・前後リンク・サイトマップのリンク先がすべて存在すること（公開前にリンク切れを機械的に検査する）
- 図が意図通り描画されているか目視
- 公開後、実URLで再確認

## やらないこと

- JavaScript（検索、フィルタ、グラフビュー等）
- ラスター画像（生成画像を含む）の埋め込み。ダークモードに追従せず、文字が画像化されるため
- 三位一体脳モデル（爬虫類脳→哺乳類脳→人間脳）の採用。現在の神経科学では否定されており、
  「上の層が下を支配する」という読み方は attention ページの内容と矛盾する。
  anatomy では解剖学的な三層のみを描き、動物の対応づけは入れない
- Digital Self（Obsidian + AI による世界モデルの外部化）— 別セクションとして切り出す
- 用語集ページ、サイト内検索
